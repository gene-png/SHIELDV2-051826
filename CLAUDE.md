\# Claude Workspace Rules



You are working inside a Docker Dev Container.



Rules:

1\. Only read, create, edit, delete, install, build, test, and run commands inside this repository.

2\. Do not access files outside the current workspace.

3\. Do not read Windows host folders, Desktop, Downloads, Documents, OneDrive, browser files, SSH keys, API keys, cloud credentials, or personal files.

4\. Do not store secrets in the repository.

5\. Do not print API keys or credentials.

6\. All development must occur inside Docker.

7\. Before major changes, explain the plan.

8\. After major changes, run git status.

9\. Commit meaningful milestones.
